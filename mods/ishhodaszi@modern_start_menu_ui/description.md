# Modern Start Menu UI

Modern Start Menu UI presents the final Gen1Recomp START menu as a compact
phone panel with a paged three-by-three icon grid. The map remains visible,
every engine or third-party action keeps its original callback, and unknown
actions receive a configurable generic icon rather than disappearing.

The presentation supports Red, Blue, Yellow, Gold, Silver, and Crystal. It
adds saved phone themes, five horizontal positions, play-time or local-device
clock labels, and a visual icon selector for third-party menu rows. Unhandled
controller hotkeys continue to reach the source controller, including
Gen1MenuManager's SELECT shortcut.

The mod is presentation-only and contains no ROM or ROM-derived assets.
